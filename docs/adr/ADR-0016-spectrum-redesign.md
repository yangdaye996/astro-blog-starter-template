# ADR-0016：视觉重设计 v3——光谱训练馆

- 状态：已采纳（2026-11-20。用户反馈「页面太单调」，全站重设计。**继承 ADR-0014 的浅色单主题、零字体/图形库依赖、大数字优先、JS 可用性分层约束**，只换设计语言。）
- 相关：ADR-0014（「墨与纸」，被本 ADR 迭代）、ADR-0011（零运行时依赖）、ADR-0015（六模块与声音）

## 背景

ADR-0014 修订版「墨与纸」克制、统一，但六模块共用一套群青墨色，页面单调、模块辨识度低。训练站需要**每个认知领域有自己的颜色身份**，以及更强的状态反馈力度。本轮把「单色墨」换成「六色光谱」。

## 决策

### 六模块色 + 语义色

- 每个模块占一支饱和色相，软底用于卡片/标签/涂卡：
  - 心算 橙 `#f76707` · N-back 靛 `#4263eb` · 舒尔特 玫红 `#e64980` · 斯特鲁普 青 `#1098ad` · 序列 紫 `#7048e8` · 冥想 松石绿 `#0ca678`
- 站点主色 = 靛蓝（品牌、链接、焦点、统计页）。
- 语义色（绿对 / 红错 / 橙警告 / 蓝信息）**严格只做状态反馈**，不做装饰，与模块色分工明确。

### 中性与形状

- 冷瓷底 `#f2f4fa`、白面 `#ffffff`、深空墨字 `#1b2138`；圆角 14px，柔和投影回归（墨与纸的近乎零阴影废弃）。
- **光谱条**：六色按暖→冷渐变（`--spectrum`），用作顶栏底部签名线、首页英雄区分隔、404 分隔——全站签名。

### 数字字体

- 计分/计时用 DIN 系 condensed 系统栈 `--font-num`（Bahnschrift / DIN Alternate / Avenir Next Condensed…），秒表感；`tabular-nums` 防跳动。中文仍系统黑体栈，零字体依赖。

### 模块换色机制

- `.mod-*` 类把 `--mod` / `--mod-soft` 指到模块色。挂 body 上整页换色（按钮、涂卡、盘面点阵、水印、导航当前页药丸）；挂首页入口卡上单卡换色。未挂类回落站点主色。

### 动效

- 首页英雄区两团模块色**漂移光晕**（环境动效，页面打开即在呼吸）+ 一次性阶梯入场（`.rise`，`--d` 控延迟）+ 训练盘面淡入。
- 全部动效尊重 `prefers-reduced-motion`。动效只答应用户动作或作一次性编排，不堆砌逐卡 hover 特效。

### 滚动条

- 全站自定义滚动条：细轨、瓷蓝 thumb、悬停加深，走站点视觉语言，不留浏览器默认灰。

### 声音

- 见 ADR-0015：事件触发音效 + 顶栏全局静音开关。

## 后果

- `base.css` 令牌整体重做，「墨与纸」令牌退役；模块专属样式仍写各页 `<style>`，跨页组件进 base.css。
- 设计评审基准：模块身份一眼可辨（颜色）、训练状态一眼看清（色 + 形）、页面有呼吸感但不吵。
- ADR-0014 的「[hidden] 与 display 覆盖」陷阱教训**继续有效**，文末兜底规则保留。
- 浅色单主题不变：每个令牌仍只有一组值，不做暗色模式。
