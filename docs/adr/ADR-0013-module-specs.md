# ADR-0013：三模块 MVP 规格——心算 / N-back / 冥想

- 状态：已采纳（2026-11-09。**玩法细节为默认值**：访谈第三轮起用户未逐项确认，按访谈中标注「推荐」的选项落定，随时可推翻重写本 ADR）
- 相关：ADR-0010（换血总纲）、ADR-0012（记录 schema 的 params/result 字段来源）

## 范围原则

一步到位做三模块 MVP：每模块一个核心玩法，做扎实，不堆模式。扩展项（双 n-back、自适应难度、引导音频等）记录在案但不实现。

## 心算（/math/）

| 项 | 规格 |
| --- | --- |
| 难度 | **手动三档**，开始前选：L1 入门 / L2 进阶 / L3 挑战。成绩只在档位内可比 |
| 题型随档位 | L1：两位数加减（和不超 100，减不出负数）；L2：三位数加减 + 两位×一位；L3：三位数加减 + 两位×一位（更大范围）+ 整除的除法 |
| 会话形式 | **限时冲刺**：30 / 60 / 120 秒三选，默认 60 秒，答尽可能多题 |
| 作答 | **键入答案**：屏上数字键盘 + 物理键盘数字，回车提交，退格改正。无选项排除法取巧 |
| 反馈 | 提交即判：答对绿灯一闪，答错短暂显示正确答案后自动下一题；提供「跳过」 |
| 成绩 | `result: { answered, correct, rate }`，核心指标 = 答对题数（档位内） |

**不做**：混合运算带括号、自适应升降档（档内微调）。

## N-back（/nback/）

| 项 | 规格 |
| --- | --- |
| 范式 | **单位置 n-back**，3×3 网格。MVP 不做双 n-back（位置+字母），结构预留 |
| n 值 | 手动选 1–5，默认 2 |
| 一轮 | `trials = 20 + n` 个刺激；刺激呈现 500ms，间隔 3000ms/刺激 |
| 目标 | 生成器保证命中目标 ≥ 6 个（随机时目标平均概率约 1/(n+1)，需构造而非纯随机） |
| 作答 | 空格键或屏上大按钮 = 「与 n 步前位置相同」；其余情况不按 |
| 计分 | `result: { hits, misses, falseAlarms, accuracy }`，`accuracy = (hits + correctRejections) / trials` |
| 结束 | 逐项反馈 + 总准确率，写入日志 |

**不做**：音频刺激、自动升降 n、字母模式。

## 冥想（/meditation/）

| 项 | 规格 |
| --- | --- |
| 形态 | 极简正念计时器 + 可选呼吸引导 |
| 时长 | 5 / 10 / 15 / 20 分钟四选 |
| 开场 | 3-2-1 倒计时 |
| 呼吸引导 | 可开关：4 秒吸 / 4 秒呼，中心圆球缩放动画 + 「吸/呼」文案。MVP 仅此一种节奏 |
| 结束 | Web Audio 合成钟声（无音频文件）；屏保式极简呈现，页面标题栏同步剩余时间 |
| 放弃 | 中途可退出，二次确认后记录 `completed: false`，时长照记 |
| 记录 | `params: { plannedMin, breathing }`，`result: { actualSec, completed }` |

**不做**：引导语音频、4-7-8 等多节奏、背景音。

## 统计页（/stats/）

- **总览卡**：总训练次数、连续天数（当日有会话则含今天）、本周次数。
- **趋势曲线**：每模块近 30 次会话一条 SVG 折线，手绘无库。心算 = 答对题数；N-back = 准确率；冥想 = 实际时长。
- **会话明细**：倒序列表（时间、模块、参数、成绩），即 ADR-0012 的日志直读。
- **导出**：JSON 下载按钮（ADR-0012 备份纪律）。
- 各列表类区块**必须有空状态设计**（继承旧规则：无数据时给引导文案，不给空白）。

## 首页（/）

三模块入口卡片 + 今日是否已练状态与连续天数（读 localStorage 现算）。JS 失效时入口链接仍可用。

## 后果

- 心算题库生成器按档位写纯函数（档位 → 题目），单元上保持可手测。
- N-back 目标构造逻辑是本模块唯一的「非平凡算法」点，实现时注释要写清目标数量的构造策略。
- 未来加双 n-back / 自适应难度 = 改 params 字段并升 schema 版本（ADR-0012），不破坏旧日志。
