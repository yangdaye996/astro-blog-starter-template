# ADR-0015：新增三模块——舒尔特方格 / 斯特鲁普 / 序列记忆

- 状态：已采纳（2026-11-20。用户要求「再想几个功能」，选定并实现覆盖注意 / 抗干扰 / 记忆广度的三个经典范式。**玩法细节为默认值**，可随时推翻重写本 ADR。）
- 相关：ADR-0010（换血总纲）、ADR-0012（记录 schema）、ADR-0013（原三模块规格）、ADR-0016（光谱视觉）

## 背景

原三模块覆盖计算速度（心算）、工作记忆（N-back）、平静专注（冥想），但缺少**注意广度、抗干扰（抑制控制）、记忆广度**三个维度。用户要求扩充功能。选型标准：经典认知训练范式、原生 JS 可实现（ADR-0011）、成绩口径清晰可趋势化。选定舒尔特方格、斯特鲁普色词、序列记忆（Corsi 式空间序列）。

## 决策

### 舒尔特方格（/schulte/）

| 项 | 规格 |
| --- | --- |
| 难度 | 3×3 热身 / 4×4 进阶 / 5×5 标准，默认 5×5。成绩只在同阶内可比 |
| 玩法 | 1 到阶数² 乱序铺满方格，从 1 按序点完；**点第一个数字起计时**；点错记一次错但不前进 |
| 反馈 | 点中涂满模块色 + 音高爬升；点错红闪抖动 + 错误音 |
| 记录 | `params: { size }`，`result: { timeSec, errors }`，核心指标 = timeSec（越低越好） |

### 斯特鲁普（/stroop/）

| 项 | 规格 |
| --- | --- |
| 难度 | 4 色（红蓝绿紫）/ 6 色（+橙青），默认 4 色 |
| 一轮 | 30 题 = 15 一致 + 15 冲突（**构造保证两组都有**，干扰效应才算得出来），乱序 |
| 作答 | 选字的**墨色**而非字义；屏上色块按钮 + 键盘 1–6 |
| 记录 | `params: { colors, trials }`，`result: { trials, correct, rate, avgMs, interferenceMs }` |
| 干扰效应 | `interferenceMs = 冲突题平均反应 − 一致题平均反应`；任一组无答对则记 0（界面显示 —）。核心指标 = rate |

### 序列记忆（/span/）

| 项 | 规格 |
| --- | --- |
| 起始 | 2 格标准 / 3 格挑战，默认 2 |
| 玩法 | 3×3 瓦片按序闪光（600ms 闪 + 280ms 隔），看完照点；每对一轮加一格，点错即止，上限 12 格 |
| 反馈 | 每格一个音高，闪光像弹琴；点对绿闪、点错红闪 |
| 记录 | `params: { startLen, flashMs }`，`result: { maxSpan, rounds }`，核心指标 = maxSpan（稳定复现的最长长度） |

### Schema 演进（关键）

- `module` 枚举**追加** `'schulte' | 'stroop' | 'span'`。条目字段结构（id / module / ts / params / result）**未变**，故**沿用 v1，不升 v2、不写迁移**——旧日志原样可读。
- 统计与明细按**模块注册表**（`assets/js/modules.js`）分发；未知模块走兜底（显示模块 id、参数/成绩为 —），不至于渲染空白。

### 声音设计

- `audio.js` 在原钟声（bell）外新增 `blip`（轻点）/ `buzz`（错误）/ `chime`（完成琶音）。**全部声音由可见事件触发**，无环境噪音。
- **全局静音开关**：顶栏一个按钮关掉全站所有声音，状态存 `mindgym:v1:sound`（`on`/`off`，默认开）。此 key 独立于会话日志，是界面偏好不是训练数据，不受 ADR-0012 的 v1 数据版本约束。

### 共享代码

- `modules.js`：六模块展示元数据 + 成绩口径（指标/单位/比较方向/参数与成绩格式化）的唯一源，首页、统计页、个人最佳共用。
- `ui.js`：`bindSeg` / `segValue`（分段选择器）、`initSoundToggle`（静音开关）、`paintTodayDots`（今日光谱点）、`fmtWhen`（时间格式化）。
- `stats.js` 新增 `bestSession`：个人最佳从日志现算（同模块可加参数过滤），不落盘。各模块结果页展示「个人最佳 / 新纪录」。

## 后果

- 导航从五链接变**八链接**（首页 + 六模块 + 统计），写死在各页 HTML，移动端横向滚动。新增页面记得同步全部页面。
- 个人最佳 / 新纪录是日志的纯函数，现算不落盘（继承 ADR-0012）。
- 三新模块各一个 JS 文件，职责单一；序列记忆的延时回调挂 runId 守卫，重开/结束后旧回调作废。
- 未来再扩模块 = 在 modules.js 注册 + 建页面目录 + 本 ADR 追加规格，schema 仍按「字段结构是否变化」决定升不升 v2。
