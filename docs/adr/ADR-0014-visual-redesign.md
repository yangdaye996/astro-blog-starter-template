# ADR-0014：视觉重设计——训练型界面，保留浅色单主题

- 状态：已采纳（2026-11-09。方向「重新设计」经用户确认；**保留浅色为默认值**——用户在第二轮明确未选暗色选项，视为接受浅色单主题延续）
- 相关：ADR-0010（换血总纲，取代 ADR-0005 的视觉基调）、ADR-0011（零运行时依赖）

## 背景

ADR-0005 的视觉是为**阅读**设计的：少数派式清爽卡片、高信息密度、蓝灰克制主色。训练应用的核心画面是**操作**：大字号计分、网格盘面、呼吸球、进度环。用户确认重新设计一套视觉，而非沿用阅读皮肤。

## 决策

### 保留的约束

- **浅色单主题**（继承 ADR-0005 精神）：每个令牌只有一组值，不做暗色模式。
- **零字体依赖**（废除 ADR-0003）：全站系统字体栈，无 fontsource。计分与时间用 `font-variant-numeric: tabular-nums` 保证跳动不抖动。
- **零图形库**（继承 ADR-0011）：动画全 CSS，图形全 SVG 手绘。

### 新设计语言：训练台

- **令牌整体重做**：`assets/css/base.css` 的 `:root` 为唯一令牌源。强调色比博客更饱满（训练需要状态反馈的力度），中性色更浅淡（界面让位给训练盘面）。
- **大数字优先**：计分、倒计时、剩余时间是每个模块页的视觉主体，字号显著大于旧博客标题层。
- **组件语言**：模块入口卡片（首页）、计时环、3×3 网格盘面、呼吸球、数字键盘。均为训练专用组件，不复用博客卡片。
- **状态反馈明确**：对/错、命中/未命中、吸/呼都有即时视觉差异（色 + 形），不依赖文字。

### JS 可用性（旧「读者端零 JS」的改写）

训练页本质是交互应用，无 JS 即无功能，这是显式接受的。改写后的规则：

- **首页与统计页在 JS 失效时仍须呈现基本骨架**（模块入口可点、空状态文案可见）。
- 训练三页 JS 失效时显示「需要启用 JavaScript」提示，不算缺陷。

## 后果

- `src/styles/global.css`、`prose.css`、`admin.css` 全部退役，样式体系从零起于 `assets/css/`。
- ADR-0005 的「[hidden] 与 display 覆盖」陷阱教训**继续有效**：新组件体系里凡设置了 `display` 的类，用 `hidden` 控显隐时必须补 `[hidden]{display:none}`。
- 设计评审基准改变：不再评「好不好读」，评「训练时一眼看清状态」。
