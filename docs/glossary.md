# 术语表

本项目领域的统一用语。写代码、写文档、讨论需求时一律使用本表术语，避免同义词漂移。（2026-11-09 随 ADR-0010 换血整体重写，博客时代术语已移除，历史文档按旧语境解读。）

## 项目与架构

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 训练站 | — | 本项目身份（ADR-0010）：心算、N-back、舒尔特方格、斯特鲁普、序列记忆、冥想六大模块 + 统计页的纯前端静态应用。正式名待定。 |
| 模块 | module | 六大训练功能之一：心算（math）、N-back（nback）、舒尔特方格（schulte）、斯特鲁普（stroop）、序列记忆（span）、冥想（meditation）。每模块一个页面目录，元数据登记在 `assets/js/modules.js`（ADR-0015）。 |
| 会话 | session | 一次完整的训练过程，从开始到结束（或明确放弃）。记录写入日志的最小单位（ADR-0012）。 |
| 会话日志 | session log | localStorage 中的追加式 JSON 数组，训练记录的唯一真源（ADR-0012）。key：`mindgym:v1:sessions`。 |
| 真源 | source of truth | 训练记录真源 = localStorage；代码真源 = git 仓库。无其他存储（ADR-0012）。 |
| 无构建 | no-build | 源码即产物：无编译、打包、转换，浏览器加载的就是仓库文件（ADR-0011）。 |
| 静态服务器 | static server | 本地开发必需——ES modules 在 `file://` 下被 CORS 拦截，必须经 HTTP 访问。`npx serve .` 或 `python -m http.server`。 |
| assets-only Worker | — | 部署形态（ADR-0011）：Cloudflare Worker 只挂静态资产目录，无 `main` 入口、无 CPU 计算。 |

## 统计与记录

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 打卡 | streak | 连续训练天数：连续自然日每天至少一条会话记录，当日已练则含今天。现算不落盘。 |
| 趋势曲线 | trend line | 每模块近 30 次会话的 SVG 折线，用模块色。心算=答对题数，N-back=准确率，舒尔特=完成用时，斯特鲁普=准确率，序列=记忆广度，冥想=实际时长（ADR-0013/0015）。 |
| 个人最佳 | personal best | 同模块（可加参数过滤，如同档位/同阶/同 n 值）里指标最优的一条会话，从日志现算（`stats.js#bestSession`），结果页展示「新纪录」。不落盘。 |
| 今日光谱 | today spectrum | 六模块各一颗色点，今日练过即填实。首页与统计页展示（`ui.js#paintTodayDots`）。 |
| 导出 | export | 把会话日志下载为 JSON 文件，localStorage 的唯一备份手段（ADR-0012）。stats 页常驻按钮。 |
| 空状态 | empty state | 无数据区块的引导文案。**每个列表类区块必须有**，继承自博客时代的规则。 |

## 心算模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 难度档 | level | 手动三档：L1 入门 / L2 进阶 / L3 挑战。题型范围与位数随档位递增，成绩只在档位内可比（ADR-0013）。 |
| 限时冲刺 | timed sprint | 会话形式：固定 30/60/120 秒内答尽可能多题，默认 60 秒。 |
| 键入作答 | typed answer | 屏上数字键盘 + 物理键盘输入，回车提交。无四选一点选。 |
| 答对题数 | correct | 心算核心成绩指标，写入 `result.correct`。 |

## N-back 模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| n 值 | n | 需要回溯比较的刺激步数，手动 1–5，默认 2。 |
| 刺激 | stimulus | 3×3 网格上一次亮起的位置，呈现 500ms、间隔 3000ms。 |
| 目标 | target | 当前刺激与 n 步前位置相同的试次。一轮 ≥ 6 个，由生成器构造保证。 |
| 命中 / 漏报 / 误报 | hit / miss / false alarm | 有目标按了=命中；有目标没按=漏报；无目标按了=误报。 |
| 准确率 | accuracy | `(hits + correctRejections) / trials`，N-back 核心成绩指标。 |

## 舒尔特方格模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 阶数 | size | 方格边长，3/4/5 三档，数字 1 到阶数²。成绩只在同阶内可比（ADR-0015）。 |
| 完成用时 | timeSec | 从点第一个数字到点完最后一个的秒数（一位小数），舒尔特核心成绩指标，越低越好。 |
| 错点 | errors | 点了非当前目标数字的次数，记错但不前进。 |

## 斯特鲁普模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 色词 | color word | 一个颜色名（红/蓝/绿/紫/橙/青）以某种墨色显示。字义与墨色可能冲突。 |
| 一致 / 冲突 | congruent / incongruent | 字义==墨色=一致；字义!=墨色=冲突。一轮 15 一致 + 15 冲突，构造保证。 |
| 干扰效应 | interferenceMs | 冲突题平均反应时 − 一致题平均反应时，越小抗干扰越强。任一组无答对记 0（ADR-0015）。 |
| 平均反应时 | avgMs | 全部答对题的反应时均值（毫秒）。 |

## 序列记忆模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 记忆广度 | maxSpan | 能稳定复现的最长闪光序列长度，序列记忆核心成绩指标（ADR-0015）。 |
| 起始长度 | startLen | 第一轮闪光格数，2 标准 / 3 挑战。每对一轮加一格，上限 12。 |
| 轮数 | rounds | 本次会话成功复现的轮数。 |

## 冥想模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 呼吸引导 | breathing guide | 可开关的 4 秒吸 / 4 秒呼圆球缩放动画 + 文案。MVP 仅此一种节奏（ADR-0013）。 |
| 钟声 | bell | 会话结束音，Web Audio API 合成，无音频文件。 |

## 界面与视觉

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 光谱训练馆 | — | 视觉设计语言 v3（ADR-0016）：六模块各占一支饱和色、光谱签名条、DIN 系数字栈、漂移光晕。继承大数字优先与训练专用组件。 |
| 模块色 | module hue | 每模块一支饱和色相（`--m-*`）+ 软底（`--m-*-soft`）。`.mod-*` 类把 `--mod` 指到模块色，挂 body 整页换色、挂入口卡单卡换色。 |
| 光谱条 | spectrum line | 六色暖→冷渐变（`--spectrum`），顶栏底部签名线 / 首页分隔 / 404 分隔。 |
| 设计令牌 | design token | `assets/css/base.css` 的 `:root`，全站唯一令牌源。每令牌一组值，**只做浅色单主题**（继承 ADR-0005 精神）。 |
| 数字等宽 | tabular-nums | `font-variant-numeric: tabular-nums`，计分与倒计时专用，防数字跳动抖宽。数字字体走 `--font-num`（DIN 系 condensed 栈）。 |
| 入口卡片 | entry card | 首页上代表一个模块的可点卡片，含模块色图标、能力标签、一句话说明、今日状态与上次成绩。 |
| 静音开关 | sound toggle | 顶栏一个按钮关掉全站所有声音，状态存 `mindgym:v1:sound`（界面偏好，非训练数据），默认开（ADR-0015）。 |
