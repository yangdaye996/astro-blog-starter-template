# 术语表

本项目领域的统一用语。写代码、写文档、讨论需求时一律使用本表术语，避免同义词漂移。

## 内容与内容模型

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 文章 | Post / `blog` collection | 技术长文。**必有标题**、描述、发布日期。有独立详情页路由 `/blog/<slug>`。 |
| 随想 | Note / `notes` collection | 短文碎碎念。**无标题**，只有正文与时间戳。不生成独立详情页，只在 `/notes` 时间轴上呈现。 |
| 内容集合 | Content Collection | Astro 的内容层概念，由 `src/content.config.ts` 中的 `glob` loader + zod schema 定义。本项目有 `blog` 与 `notes` 两个。 |
| 前置元数据 | frontmatter | Markdown 文件顶部 YAML 块中的结构化字段，由 zod schema 校验。 |
| 封面图 | `heroImage` | 文章卡片顶部与详情页头部的大图。可选字段；缺失时卡片不渲染图片区域。 |
| 标签 | `tags` | 文章的多值分类，`string[]`，默认空数组。**仅用于列表页前端筛选**（ADR-0006）。 |
| 分类 | `category` | 文章的单值频道划分，可选。**仅用于列表页前端筛选**（ADR-0006）。 |
| 草稿 | draft | 尚未发布的文章。**本项目不支持该字段**——清空后的 collection 不引入 draft 机制，未完成的文稿不放进 `src/content/`。 |

## 页面与导航

| 术语 | 路由 | 定义 |
| --- | --- | --- |
| 首页 | `/` | 单栅卡片流，文章最新在上。不做 hero、不做侧边栏（ADR-0005）。 |
| 列表页 | `/blog` | 全部文章的卡片流，顶部带筛选芯片。 |
| 文章详情页 | `/blog/<slug>` | 单篇文章正文，含 TOC、字数与阅读时长、上一篇/下一篇、封面图。 |
| 归档页 | `/archive` | 按年份分组的时间轴，列出全部文章。 |
| 随想页 | `/notes` | 无标题时间轴，按日期倒序排列随想条目。 |
| 关于页 | `/about` | 作者自我介绍。 |
| 空状态 | empty state | 列表类页面无内容时呈现的提示文案。因 ADR-0007 清空了全部示例内容，**每个列表页都必须有空状态设计**。 |

## 界面元素

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 卡片 | card | 列表页与首页上代表一篇文章的矩形块，含标题、描述、日期、分类/标签徽标、字数与阅读时长。 |
| 单栅卡片流 | single-column card stream | 卡片单列纵向铺满内容区的布局。本项目首页与列表页的唯一布局形态。 |
| 筛选芯片 | filter chip | 列表页顶部的可点击标签胶囊，点击即在当前页过滤卡片，不跳转。 |
| 徽标 | badge | 卡片与详情页上显示分类/标签的小型彩色标记，不可点击（区别于筛选芯片）。 |
| 文章目录 | TOC (Table of Contents) | 从 Markdown 标题层级构建期生成的目录，客户端用 `IntersectionObserver` 做滚动高亮。 |
| 阅读时长 | reading time | 构建期按中文字数估算的阅读耗时，与字数一同显示。 |
| 时间轴 | timeline | 归档页与随想页的竖向线性布局，以日期为节点。 |

## 排版与字体

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 标题层 | heading layer | 使用思源黑体 Bold 子集的所有文字：站名、导航、栏目标题、文章标题。 |
| 正文层 | body layer | 使用中文系统字体栈的所有文字：正文、卡片描述、元信息。 |
| 字体子集 | font subset | 从完整中文字体中裁出仅含实际用到字符的小体积字体文件。 |
| 动态子集 | dynamic subset | 构建期扫描全站标题字符后生成的子集，覆盖站名、导航与**全部文章标题**。对应产物 `public/fonts/heading-subset.woff2`（ADR-0003）。 |
| 系统字体栈 | system font stack | 按平台优先级排列的本地字体列表：苹方 / 冬青黑 / 思源黑 / 微软雅黑，零下载。 |
| 思源黑体 | Source Han Sans | Adobe 与 Google 合作的中文字体，SIL OFL 授权。 |
| Noto Sans SC | — | 思源黑体的 Google 发行版，同一套字形、同一授权。本项目通过 `@expo-google-fonts/noto-sans-sc` 取得完整 TTF 作为子集输入。 |

## 构建与渲染

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 纯静态预渲染 | static prerender | 全部页面在 `astro build` 时生成 HTML，Worker 只发静态文件。本项目唯一支持的渲染模式（ADR-0001）。 |
| 构建时预渲染 | build-time prerender | 把重计算内容（Mermaid SVG、KaTeX HTML、字体子集、字数）在构建期算完并写进产物，读者端零 JS。 |
| 静态资源托管 | Workers Static Assets | Cloudflare Workers 通过 `wrangler.json` 的 `assets.directory` 直接伺服 `dist/`，不执行用户代码，不消耗 Worker CPU/内存配额。 |
| 设计令牌 | design token | `global.css` 中 `:root` 下的 CSS 自定义属性（颜色、间距、圆角、阴影）。因不做暗色模式，**每个令牌只有一组值**（ADR-0005）。 |
| 少数派式清爽卡片 | — | 本项目的视觉基调：蓝灰主色、高信息密度卡片、细边框轻阴影、细线分隔与充足留白（ADR-0005）。 |

## 明确不在范围内的术语

以下概念在本项目中**不存在**，讨论时不要预设它们可用：

| 术语 | 状态 |
| --- | --- |
| 暗色模式 / dark mode | 不做（ADR-0005）。 |
| SSR / 服务端渲染 | 不做（ADR-0001）。 |
| RSS / 订阅源 | 已删除（ADR-0007）。 |
| sitemap / 站点地图 | 已删除（ADR-0007）。 |
| 评论 / comment | 无写入型功能（ADR-0001）。 |
| 站内搜索 / search | 只有列表页筛选，无全站搜索（ADR-0006）。 |
| 友链页 / 项目页 | 未选（页面清单决策）。 |
| 分类页 / 标签页 | 不做聚合路由（ADR-0006）。 |
| i18n / 多语言 | 单语中文站。 |
