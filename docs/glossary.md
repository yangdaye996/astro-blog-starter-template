# 术语表

本项目领域的统一用语。写代码、写文档、讨论需求时一律使用本表术语，避免同义词漂移。（2026-11-09 随 ADR-0010 换血整体重写，博客时代术语已移除，历史文档按旧语境解读。）

## 项目与架构

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 训练站 | — | 本项目新身份（ADR-0010）：心算、N-back、冥想三大模块 + 统计页的纯前端静态应用。正式名待定。 |
| 模块 | module | 三大训练功能之一：心算（math）、N-back（nback）、冥想（meditation）。每模块一个页面目录。 |
| 会话 | session | 一次完整的训练过程，从开始到结束（或明确放弃）。记录写入日志的最小单位（ADR-0012）。 |
| 会话日志 | session log | localStorage 中的追加式 JSON 数组，训练记录的唯一真源（ADR-0012）。key：`mindgym:v1:sessions`。 |
| 真源 | source of truth | 训练记录真源 = localStorage；代码真源 = git 仓库。无其他存储（ADR-0012）。 |
| 无构建 | no-build | 源码即产物：无编译、打包、转换，浏览器加载的就是仓库文件（ADR-0011）。 |
| 静态服务器 | static server | 本地开发必需——ES modules 在 `file://` 下被 CORS 拦截，必须经 HTTP 访问。`npx serve .` 或 `python -m http.server`。 |
| assets-only Worker | — | 部署形态（ADR-0011）：Cloudflare Worker 只挂静态资产目录，无 `main` 入口、无 CPU 计算。 |

## 统计与记录

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 打卡 | streak | 连续训练天数：连续自然日每天至少一条会话记录，当日已练则含今天。现算不落盘。 |
| 趋势曲线 | trend line | 每模块近 30 次会话的 SVG 折线。心算=答对题数，N-back=准确率，冥想=实际时长（ADR-0013）。 |
| 导出 | export | 把会话日志下载为 JSON 文件，localStorage 的唯一备份手段（ADR-0012）。stats 页常驻按钮。 |
| 空状态 | empty state | 无数据区块的引导文案。**每个列表类区块必须有**，继承自博客时代的规则。 |

## 心算模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 难度档 | level | 手动三档：L1 入门 / L2 进阶 / L3 挑战。题型范围与位数随档位递增，成绩只在档位内可比（ADR-0013）。 |
| 限时冲刺 | timed sprint | 会话形式：固定 30/60/120 秒内答尽可能多题，默认 60 秒。 |
| 键入作答 | typed answer | 屏上数字键盘 + 物理键盘输入，回车提交。无四选一点选。 |
| 答对题数 | correct | 心算核心成绩指标，写入 `result.correct`。 |

## N-back 模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| n 值 | n | 需要回溯比较的刺激步数，手动 1–5，默认 2。 |
| 刺激 | stimulus | 3×3 网格上一次亮起的位置，呈现 500ms、间隔 3000ms。 |
| 目标 | target | 当前刺激与 n 步前位置相同的试次。一轮 ≥ 6 个，由生成器构造保证。 |
| 命中 / 漏报 / 误报 | hit / miss / false alarm | 有目标按了=命中；有目标没按=漏报；无目标按了=误报。 |
| 准确率 | accuracy | `(hits + correctRejections) / trials`，N-back 核心成绩指标。 |

## 冥想模块

| 术语 | 英文/代码标识 | 定义 |
| --- | --- | --- |
| 呼吸引导 | breathing guide | 可开关的 4 秒吸 / 4 秒呼圆球缩放动画 + 文案。MVP 仅此一种节奏（ADR-0013）。 |
| 钟声 | bell | 会话结束音，Web Audio API 合成，无音频文件。 |
| 完成 | completed | 会话自然走完计时 = true；中途确认退出 = false，时长照记（`result.actualSec`）。 |
